# 熊貓儲存工具 · 把 GitHub 倉庫當網盤的桌面工具

[![Release](https://img.shields.io/github/v/release/kite88/panda-storage-tool-release?style=flat)](https://github.com/kite88/panda-storage-tool-release/releases/latest)

一個跨平臺桌面工具（Avalonia UI / .NET 10），把 **GitHub 倉庫當成網盤**：檔案或整個資料夾拖進視窗就完成上傳，
之後像檔案管理器那樣逐級瀏覽、下載、重新命名、批次刪除，並順手拿到可以直接分享的外鏈（raw / jsDelivr）。

檔案型別不限——圖片、文件、壓縮包、音影片、程式碼都能放進來管理；區別只在顯示上：圖片給縮圖，
其它檔案給「副檔名 + 文件輪廓」的型別徽標。唯一被特殊對待的是 `.gitkeep`：它是程式用來撐住空目錄的
佔位檔案，只在倉庫裡存在，不出現在列表裡。

Windows / macOS / Linux 三平臺，中英雙語介面與亮暗主題；釋出包是**自包含單檔案，免裝 .NET 執行時**，解壓即用。

## 功能特性

- **拖拽 / 貼上上傳**：把檔案或資料夾拖到列表區域即上傳到當前目錄；`Ctrl + V` 能把剪貼簿裡的點陣圖
  （截圖、網頁上覆制的圖片）或資源管理器裡複製的檔案直接傳上去；檢視區右鍵選單裡也有「上傳檔案 / 上傳資料夾 / 貼上」。
- **上傳整個資料夾**：按本地原有的子目錄結構遞迴上傳到當前目錄下的同名資料夾，
  每一級都會補 `.gitkeep`，一個檔案都沒有的空子目錄也會被建出來（目錄結構在倉庫裡保持完整）。
- **目錄瀏覽（雲盤式）**：雙擊進子目錄、麵包屑跳回任意一級；子目錄顯示其下（含各級子目錄）的檔案數量；
  只有 `.gitkeep` 的空目錄同樣顯示（計數為 0）。根目錄就是儲存設定裡配的那個「根目錄」，留空即整個倉庫。
- **下載**：右鍵單個檔案「下載到本地…」；右鍵子目錄「下載到資料夾…」會把該目錄本身連同各級子目錄一起還原；
  勾選多個條目後一次可批次下載（落盤按「相對當前目錄的路徑」，不同目錄下的同名檔案不會互相覆蓋）。
- **傳輸記錄頁**：上傳 / 下載逐條留痕（方向、檔名與倉庫路徑、大小、時間、成功或失敗），
  可按方向只看上傳 / 只看下載；每行能「定位」（下載記錄開啟落盤位置，上傳記錄跳到它所在目錄）或刪掉這一條。
- **看大圖**：點圖片卡片的縮圖彈出預覽視窗，支援 `＋ / －`、適應視窗、`Ctrl + 滾輪`縮放，`Esc` 關閉。
- **外鏈隨手複製**：右鍵「複製」子選單裡有 URL / Markdown / HTML，圖片給 `![](...)`、其它檔案給 `[](...)`，
  外鍊形式可選 `raw.githubusercontent.com`、jsDelivr 加速或自定義模板。
- **重新命名與刪除**：右鍵或按 `F2` 改名（檔案只換名字不動內容，外鏈與引用文字一起更新）；
  刪除單個檔案 / 整個子目錄，或勾選一片後批次刪除（刪除前有確認，刪除過程能實時看到進度）。
- **重名策略**：自動重新命名 / 覆蓋 / 報錯，在儲存設定裡選。
- **重置儲存設定**：儲存設定底部的「重置」一鍵清空 Token、擁有者、倉庫名與根目錄
  （外鍊形式、重名處理、提交資訊回到預設值）；本機的檔案列表與傳輸記錄保留，確認後立即生效。
- **恢復出廠設定**：設定裡第三個選項卡把本機資料目錄整個清空（配置、縮圖快取、上傳中轉檔案）
  並自動重新啟動程式，等於剛裝好——倉庫裡的檔案一個都不動。
- **主題與語言**：亮色 / 暗色 / 跟隨系統；簡體中文 / 繁體中文 / English / 跟隨系統，選中即時生效並寫入配置。
- **檢查更新**：在「關於」裡可以手動查一次最新版本，程式啟動時也會靜默查一次（一天至多一次）；
  比對時只認與當前執行平臺匹配的安裝包，只發了別的平臺的包不會誤報。
  「關於」裡的官網與 GitHub 地址是開啟視窗時從發版倉庫的 `appinfo.json` 現取的，以後改地址不必再發一個新版本。
- **快捷鍵**：`Ctrl + V` 上傳剪貼簿內容、`Delete` 刪除勾選項、`F2` 重新命名當前條目。

## 下載與執行

從 [Releases](https://github.com/kite88/panda-storage-tool-release/releases/latest) 下載對應平臺的包：

| 檔案 | 適用 |
| --- | --- |
| `PandaStorageTool-win-x64-<版本>.zip` | Windows 64 位（Intel / AMD，最常見） |
| `PandaStorageTool-win-x86-<版本>.zip` | Windows 32 位 |
| `PandaStorageTool-win-arm64-<版本>.zip` | Windows on ARM（如驍龍筆記本） |
| `PandaStorageTool-linux-x64-<版本>.tar.gz` | Linux 64 位（Intel / AMD） |
| `PandaStorageTool-linux-arm64-<版本>.tar.gz` | Linux ARM64 |
| `PandaStorageTool-osx-x64-<版本>.tar.gz` | macOS（Intel） |
| `PandaStorageTool-osx-arm64-<版本>.tar.gz` | macOS（Apple 晶片） |

- 都是**自包含單檔案包，免裝 .NET 執行時**：Windows 解壓得到 `PandaStorageTool.exe` 雙擊即用；
  Linux / macOS 解壓後 `chmod +x PandaStorageTool` 再執行。
- Windows 首次執行若彈出「Windows 已保護你的電腦」（SmartScreen 未簽名提示，正常現象）：點「更多資訊」→「仍要執行」；
  也可以先右鍵 `PandaStorageTool.exe` → 屬性 → 勾選「解除鎖定」，或在 PowerShell 裡 `Unblock-File .\PandaStorageTool.exe`。
- macOS 首次開啟若被系統攔下，去「系統設定 → 隱私與安全性」放行即可。
- `checksums.txt` 是上面所有包的 SHA256 校驗和（`sha256sum -c checksums.txt`）。
- 解除安裝即刪：程式不寫登錄檔、不裝服務，唯一的落盤資料是下面說的配置目錄。

## 使用前準備

1. **準備一個用來存檔案的倉庫**：可以是新建的空倉庫，也可以複用已有倉庫。
   **建議用公開倉庫**——只有公開倉庫才能讓 raw / jsDelivr 外鏈被匿名訪問；私有倉庫能上傳，但外鏈別人打不開
   （程式在「測試連線」時會給出對應的橙色提醒）。
2. **生成一個 Personal Access Token**：GitHub → Settings → Developer settings → Personal access tokens，
   勾選倉庫內容的讀寫許可權（classic 選 `repo` 或 `public_repo`；fine-grained 選 `Contents: Read and write`）。
3. 開啟程式 →「設定」→「儲存設定」：**儲存型別**選「GitHub 倉庫」，填 Token、擁有者 Owner、倉庫名 Repo、
   分支 Branch；點「測試連線」確認無誤後儲存。**儲存時程式會先自動測一次連線**：連不上就不寫配置、
   也不關視窗，改完可以直接再點儲存；儲存成功後會自動以倉庫內容為準同步一次。
4. **根目錄**決定雲盤從倉庫的哪一層開始：預設為空，即整個倉庫都是雲盤範圍；填 `files`、`assets`
   之類的目錄名則把範圍收窄到該目錄，倉庫裡的 README、`.github/` 等就不會出現在列表裡。

Token 只儲存在本機（見下一節），不會發給除 GitHub 之外的任何地方。

## 使用說明

1. **上傳**：把檔案拖到列表區域（或按 `Ctrl + V` 貼上、右鍵「上傳檔案」）→ 上傳到**當前目錄**；
   拖資料夾則按原有目錄結構遞迴上傳。多檔案會逐個提交，狀態列顯示「上傳中 2/5」，失敗的可右鍵重試。
2. **瀏覽**：雙擊子目錄進入，點麵包屑跳回任意一級；右上角可在**網格**（縮圖卡片）與**列表**
   之間切換，選擇會被記住。
3. **選擇與批次操作**：左擊卡片＝單選，`Ctrl` 加選、`Shift` 連選，空白處拖框多選，空白處單擊全部取消；
   勾選後目錄欄會出現「刪除選中」「下載選中」，右鍵選單裡也有。
4. **下載**：右鍵檔案「下載到本地…」，右鍵子目錄「下載到資料夾…」，或勾選一片後「下載選中」。
5. **拿外鏈**：右鍵卡片 →「複製」→ URL / Markdown / HTML，複製後彈一句氣泡提示。
6. **傳輸記錄**：切到「傳輸」頁看每一次上傳與下載；頂部可按方向篩選，右上角「清空上傳記錄 /
   清空下載記錄」只清留痕，不動倉庫裡的檔案。
7. **設定**：右上角「設定」圖示按鈕 →「常規設定」裡切換主題與語言（即點即生效）；
   「儲存設定」裡改 Token、倉庫、根目錄（點「重置」可清空重填）；
   想徹底重來就用第三個選項卡「恢復出廠設定」——清空本機資料後程式會自己重啟，倉庫裡的檔案不動。

## 資料放在哪

```
%LOCALAPPDATA%\PandaStorageTool\
├─ appdata.json   Token、儲存設定、上傳歷史、佔位目錄清單、傳輸記錄
├─ appinfo.json   「關於」視窗的官網 / GitHub 地址快取（開啟視窗時從發版倉庫現取）
├─ thumbs\        縮圖快取（按內容命名，可能被多條記錄共用）
└─ temp\          上傳中轉
```

macOS / Linux 位於對應的應用資料目錄下。需要重置時不必手動刪目錄：程式裡「設定 → 恢復出廠設定」
會清空這個目錄並自動重啟（Token 也一併清除）；當然，關掉程式手動刪掉它效果一樣。

## 已知限制

- GitHub Contents API 單檔案建議 ≤ 100 MB，超大檔案請改用 Git LFS 或 Git Data API。
- 非圖片檔案只顯示型別徽標，不做內容預覽；要看內容請用右鍵選單裡的「開啟外鏈」。
- 上傳資料夾是「一個檔案一次提交」（外加每個空目錄一次佔位提交），檔案很多時比較慢，
  也容易撞到 GitHub 的 API 速率限制（每小時 5000 次請求）。
- 重新命名（含子目錄改名）是「讀到新路徑 + 刪掉舊路徑」，每個檔案一次提交；中途失敗可能只搬了一半，
  右鍵選單裡的「重新整理」會按倉庫內容重新對齊列表。
- jsDelivr 有快取，刪除或覆蓋同名檔案後外鏈可能短暫仍可訪問。
- 同步與「重新整理」走 Git Trees API：倉庫檔案極多時 GitHub 會截斷返回結果，
  且「根目錄」是客戶端過濾（一次請求拿全樹後按目錄篩）。
- 空目錄的顯示以本地記錄為準：在別處（網頁 / 命令列）刪掉的空目錄，要等「重新整理」或「拉取儲存庫」之後才會消失。
- 更新檢查是**匿名**請求 GitHub 介面（同 IP 每小時 60 次），被限流或斷網時只會顯示一句「檢查更新失敗」，
  不影響其它功能。這裡查的是「正式釋出」，預釋出與草稿不算數；一個正式版本都沒有時會顯示
  「還沒有正式版本釋出。」（這不算失敗）。
- 「關於」裡的官網與 GitHub 地址取自發版倉庫的 `appinfo.json`（GitHub 直鏈與 jsDelivr 兩條路一起取，
  誰先拿到有效內容用誰）；兩條都取不到就用本機的舊快取，連快取都沒有時這兩行乾脆不顯示。
- 「恢復出廠設定」刪的是本機檔案，被另一個例項佔著就可能刪不乾淨：此時程式**不會重啟**，
  只提示關掉其它例項再試；新例項起不來時也會提示手動重開（資料已經清掉了）。
